VAAZHVU: hearing when a machine is about to fail

Edge AI, ESP32-S3, TensorFlow Lite INT8

Factories stream sensor data from every machine, which drains batteries and clogs networks as they scale. VAAZHVU asks whether a sensor can stay quiet until something actually changes. It's a small device that listens to a machine and flags faults on the spot, without sending audio to the cloud. It extracts 70 time, frequency and MFCC features from every half-second of sound, then runs two models side by side: an autoencoder that notices anything unusual, and a classifier that names known faults. Results sync to a digital twin, so the virtual copy of the machine stays up to date without a constant data stream.

  • 85.3%accuracy in heavy noise (0 dB SNR)
  • <6%false alarms
  • 32 KBmodel size on the chip
  • 91.2%less wireless data sent

ArrhythmiaGuard: explainable heartbeat classification on a microcontroller

TinyML, ESP32-S3, AD8232 ECG sensor, SHAP

Real-time arrhythmia detection that runs on the device and shows why it made each call. I evaluated it on the MIT-BIH dataset under the AAMI EC57 inter-patient protocol, where the model is scored on patients it never trained on, which is the honest test for a medical model.

Along the way I found and fixed an undocumented TensorFlow Lite 2.19 bug where the deployed model returned only zeros, using hybrid INT8/float32 inputs and outputs.

  • 0.942AUC, Random Forest
  • 0.908AUC, 1D CNN
  • Top 50teams, TNWise 2026

Combining five foundation models to map the brainstem

PyTorch, GigaPath, Virchow, UNI2, PathDino, CONCH, DINO distillation

I fused embeddings from five pretrained pathology foundation models, with DINO teacher–student distillation, to classify 11 brainstem regions in whole-slide images, and ran ablations to find which combinations help. I also built a memory-safe pipeline streaming 1,557 tissue patches from AWS S3, and a classifier plugin that cut manual annotation effort by 60% using only 5 labelled slides.

  • 80.81%accuracy, 11 classes
  • 60%less manual annotation
